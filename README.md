# Li Qiao Academic Homepage

This repository hosts the source code for Li Qiao's academic homepage:

https://liqiao19.github.io/

The site is built with Jekyll and based on the Academic Pages template. It contains public academic information only: biography, publications, selected projects, patents, academic services, talks, and related links.

## Privacy Notes

Do not commit private information, unpublished follow-up work, local files, credentials, review materials, or non-public datasets to this repository. Content in this repository should be treated as publicly visible.
